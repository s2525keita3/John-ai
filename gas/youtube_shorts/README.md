# ぴゅあの日常 ショート自動投稿（GAS）

Driveフォルダ「tiktok動画」の動画を、毎日1本ずつ YouTube チャンネル「ぴゅあの日常」にショートとして投稿し、
投稿済みは `01_投稿済み/` サブフォルダへ移動する。vidIQ 等の外部サービスは使わない。

運用手順の正本は Vault: `09_Marketing/youtube/ぴゅあの日常_ショート自動投稿_運用手順.md`

## ファイル
| ファイル | 役割 |
|---|---|
| `00_Config.gs` | 設定キーと既定値 |
| `01_Setup.gs` | メニュー、初期セットアップ、トリガーON/OFF |
| `02_Queue.gs` | Drive → 「投稿キュー」シート |
| `03_Caption.gs` | タイトル・説明文の自動生成（ファイル名のキーワードから） |
| `04_Post.gs` | YouTube Data API でアップロード、フォルダ移動、ログ |
| `appsscript.json` | マニフェスト（YouTube 高度なサービス・スコープ） |

## セットアップ（5分）
1. s2525keita3 で新規スプレッドシートを作る（「ぴゅあの日常」の管理者権限があること）
2. 拡張機能 → Apps Script → 上記 `.gs` を貼り付け、`appsscript.json` も「プロジェクトの設定 → マニフェストを表示」で置き換える
3. 左メニュー「サービス」→ **YouTube Data API v3** を追加
4. シートを再読み込み → メニュー「ショート投稿」→ ⓪ 投稿先チャンネルを確認（初回は権限承認）→ ① 初期セットアップ
5. 「投稿キュー」でファイル名をクリックして動画を確認し、文面を直し、投稿してよいものだけステータスを「承認」にする
6. ③ 今すぐ1本投稿 で動作確認（最初の3本は限定公開）→ ④ 毎日自動投稿をON

## 制約
- YouTube Data API の無料クォータは 1日 10,000 ユニット。アップロード1本 = 1,600 ユニットなので **1日最大6本**。既定は1本/日
- Google Cloud で OAuth 同意画面が「テスト」状態のアプリは、公開動画のアップロードが制限される場合がある（動画が非公開固定になる）。その場合は Cloud Console でアプリを公開（審査不要の内部利用または確認申請）する
- 動画はサブフォルダ（例 `26年10月/ジョン様/`）に入れてもよい。`01_投稿済み` と `99_エラー` の中は読まない
- 大きな動画は8MBずつ小分けにして送る（目安 500MB まで）
- 動画は 60秒以内・縦型でないとショートとして扱われない
- 実行アカウントは `tiktok動画` フォルダの**編集権限**が必要（2026-10-21 方針：s2525keita3 に編集権限をもらって s2525keita3 で実行）
- 投稿先は**実行アカウントの既定チャンネル**。「ぴゅあの日常」がブランドアカウントの場合、YouTube でそのチャンネルに切り替えた状態で権限承認すること。メニュー「⓪ 投稿先チャンネルを確認」で確認でき、違うチャンネルなら投稿は自動で止まる

## 運用ルール（2026-10-21 決定）
- 承認制：ステータス「承認」の動画だけ投稿。新しい動画は「未承認」で入る
- 最初の3本は限定公開、以降は公開
- 1日1本・19時台
- 投稿後は `01_投稿済み/` へ移動
- 採用ページURLは設定シートの RECRUIT_URL（要確認）
