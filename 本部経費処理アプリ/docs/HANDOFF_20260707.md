## 桜木町の分類ポリシー（オーナー確認済み）

- **除外**（`aozora_filters.py`）: スタッフ給与振込（姓カナで判定）・カ）ジヨンへの
  振替（本部送金）・ATMゆうちょ（小口補充）・PE電子納付・社会保険料
  → 支給控除一覧・小口帳側で把握するため二重計上防止。
- **入金に分類**: 医療保険入金（国保連・支払基金）／リコーリース（利用者負担金の
  集金代行）／高齢福祉課／利用者個人の振込。
- **エイトプラス・イナミ シャーリーモモ = 車屋**（修理・軽自動車購入）
  → 車両運搬費。給与ではない（一度誤って除外し訂正済み。摘要の見た目で
  推測せず、不明な支払先はオーナーに確認すること）。
- リコーリースは表記で区別: 「リコ－リ－ス」（全角ハイフン・入金）と
  「リコーリース」（長音・リース料）。脆い区別なので触るとき注意。

## 開発環境の注意（このリポジトリ固有）

- ソースは OneDrive 配下。`git status` が非常に遅い（タイムアウトすることも）。
  ファイル指定で `git add` する。
- OneDrive の影響で commit が `cannot update the ref` で失敗する場合は
  `git config windows.appendAtomically false`（設定済み）。
- マスタ・コードを直したら **必ず GitHub へ push**。ローカルだけ直すと
  デプロイ側で判断不能が再発する（実際に発生した）。
